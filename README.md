# MIWEB GUZMAN_FABIAN

Proyecto educativo desarrollado por **Fabian Enrique Guzman Choque**

## Descripción
Este proyecto contiene tres programas Python para realizar cálculos matemáticos básicos:

- **principal.py**: Programa principal que muestra la información del desarrollador
- **suma.py**: Calcula la suma de 2 números
- **factorial.py**: Calcula el factorial de un número

## Funcionalidades

### 1. Suma de números
```bash
python suma.py
```
Permite ingresar dos números y calcula su suma.

### 2. Factorial
```bash
python factorial.py
```
Calcula el factorial de un número ingresado.

### 3. Información Principal
```bash
python principal.py
```
Muestra la información del desarrollador.
